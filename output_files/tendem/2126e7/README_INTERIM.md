# Interim Weekly Aggregates — Reddit + GitHub

**Status:** Twitter/X is **deferred** and not included in this interim dataset.  
This file set currently contains **Reddit** and **GitHub** only. The schema is stable and ready for later inclusion of **X** without breaking changes.

## Quick summary (for reviewers)
- **Weeks covered:** 57 (Monday-based, from 2024-09-02 to 2025-09-29)
- **Platforms present:** GitHub, Reddit
- **Total rows:** 114 (≈ weeks × platforms)

- `interim_weekly_aggregates_reddit_github.xlsx` — same data in Excel; includes a **validation** sheet

`Platform`, `Week Starting Date`, `Top Trending Topic`, `Engagement Score`, `Post Count`, `User Interactions`
