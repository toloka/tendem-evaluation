## Sparse fields (coverage variability)

For quick expectations across the 20 posts:
- **commenter_profile_url** — often blank because many sites remove the Website/URL field from the WordPress comment form via filters; linked names are therefore not always present.
- **reactions_count** — only populated where comment likes/upvotes are enabled (usually via plugins/3rd-party platforms); many sites don’t expose this, so it remains blank.
